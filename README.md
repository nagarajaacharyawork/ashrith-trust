# Ashrith Group of Institutions — Website

Official website for Ashrith Trust (R), Kota, Udupi, Karnataka.

## Development

Requires Node.js and npm.

```sh
npm install
npm run dev
```

## Build & Deploy

```sh
npm run build   # outputs to dist/
```

Deploy the `dist/` folder to Vercel as a static site. The `vercel.json` handles SPA routing.

## Stack

- Vite + React 19
- TypeScript
- TanStack Router (client-side)
- Tailwind CSS v4
